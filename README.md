# 🎮 Game Hub

A collection of 5 challenging mini-games in a single application, built with Python and Pygame.

## Games Included

1. **Flappy Bird** - Navigate through pipes, avoid blue walls to survive. Endless scoring on pipe crossings.
2. **Arrow Shooter** - Shoot moving targets. Score on hits, game ends after 5 misses.
3. **Breakout** - Classic brick breaker with paddle and ball.
4. **Space Invaders** - Defend against alien invaders.
5. **Snake** - Classic snake game, eat food to grow, avoid walls and self.

## Controls

- **Menu**: Click buttons to select games
- **Flappy Bird**: SPACE to jump
- **Arrow Shooter**: LEFT/RIGHT arrows to move, SPACE to shoot
- **Breakout**: LEFT/RIGHT arrows to move paddle
- **Space Invaders**: LEFT/RIGHT arrows to move, SPACE to shoot
- **Snake**: Arrow keys to change direction
- **All Games**: ESC to return to menu

## Features

- Endless gameplay with scoring
- Challenging mechanics
- Colorful interface
- Single executable
